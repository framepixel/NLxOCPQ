# Fine-tuning environment for the transformers-v5 model set — conda env, Python 3.10, H100.
# Used by submit_job_v5_*.sh for ALL THREE models (Llama 3.1 8B, Ministral 3 14B, Gemma 3 4B),
# so every adapter in the results comes from one dependency stack.
#
# SEPARATE from `nlxocpq-train-next` / requirements.unsloth-train.txt on purpose. Ministral 3
# needs transformers v5, while that env pins transformers 4.57.6 and produced the superseded
# adapters. Upgrading it in place would have made those results unreproducible
# (CLAUDE.md 2.2: never upgrade a package mid-experiment without a new named environment).
# The older file stays as the provenance record of the superseded runs.
#
# Create with:
#   conda create -n nlxocpq-train-v5 python=3.10 -y
#   conda activate nlxocpq-train-v5
#   pip install -r requirements.unsloth-train-v5.txt
# `nlxocpq-train-v5` is the default in prefetch_models.sh and every submit_job_v5_*.sh, so no
# export is needed once it exists. If you would rather reuse `nlxocpq-spike-ministral` (the env
# the Ministral spike ran in - same stack), set OCPQ_TRAIN_ENV=nlxocpq-spike-ministral instead.
# Do not leave the two names disagreeing: with both envs present, a forgotten export would run
# training in an environment other than the one these pins describe.
#
# RECONCILED 2026-08-14 against `pip freeze` from `nlxocpq-train-v5` — the environment that ran
# the 2026-08-13 jobs (LLaMA 3.1 to completion; Gemma 3 and Ministral 3 to step 5750 before an
# unrelated filesystem fault). Every version below is observed, not intended. This discharges the
# earlier note in this file that "a pin nobody has run is worse than no pin".
#
# Two things worth knowing before editing:
#   * `unsloth_zoo` is 2026.8.9 while `unsloth` is 2026.8.12 — they are NOT released in lockstep.
#     Do not "correct" the zoo pin to match unsloth.
#   * `packaging` is provided by conda in this env (`pip freeze` shows a file:// path, no
#     version), so it is deliberately absent below; pip pulls a compatible build transitively.
#   * `torchaudio` is NOT installed. Only torch / torchvision / torchao are present.
